# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and accept constructive criticism, and focus on what is best for the
people who use and build Lydite. Harassment, insults, personal attacks and publishing others' private information are
not accepted, in this repository and in any space linked to it.

## Reporting

To report a conduct problem privately, use the **Security** tab of this repository, then **Report a vulnerability**,
and start the title with `Conduct:`. Only the maintainers see it. You may also contact the repository's owner through
their GitHub profile.

The maintainers review every report promptly and fairly, keep the reporter's identity private, and apply the
enforcement guidelines of the Contributor Covenant 2.1, from a private correction to a permanent ban.
